# Security Policy

## Development & Pre-Audit Disclaimer

**`escrow` is under active development (WIP) and has NOT been audited.**
- Several cross-contract deployment hooks and accounting settlement paths (e.g., account deployer address wiring in `RiftHub.sol`, `judgeDeployer` wiring in `real-world-bargain/bargain.sol`, fee-manager integration, and comprehensive test coverage) are still in progress.
- Do **not** deploy these contracts to mainnet or entrust real funds of value.

## Vulnerability Reporting

Please disclose security findings privately via [@OX_SHAH](https://x.com/OX_SHAH) or GitHub Security Advisories rather than opening public exploit issues.
